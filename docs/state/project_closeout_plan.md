
完整放电测试已通过当前阶段验证。剩余主线是：必要代码清洗、充电曲线、充电截止及温升验证、结果回填和最终文档定稿。

## 3. 本轮代码清洗范围

只允许处理以下四类代码修改：

1. 预放电生产闭环。
2. SC8815 INT 的 CubeMX EXTI 配置和任务 flag 消费。
3. RTOS 时间单位转换与固定周期调度。
4. 必需外设初始化失败时禁止进入正常 RUN。

本轮禁止顺手修改：

- 已通过的放电核心策略。
- SOC/SOH/OCV 算法。
- BQ/SC 保护阈值和寄存器配置。
- Debug CLI 默认 CSV。
- 看门狗、CI 和大规模架构重构。

### 2026-07-13：清洗完成后的基础回归与充电测试

前置条件：必要代码修改已完成，Debug/Release 至少有一条可重复构建路径，固件已烧录。

执行顺序：

1. 冷启动与初始化检查。
2. 必需外设失败禁止 RUN 的故障注入。
3. SC8815 EXTI 触发和任务状态读取。
4. PDSG 预放电成功、超时、失败关断。
5. 放电链路必要回归。
6. 按 `docs/test/ai_charge_curve_test_task.md` 采集充电曲线。

若清洗未达到测试前置条件，充电测试顺延，不允许带着未确认的功率链路修改直接长时间充电。

## 5. 充电测试后的结果回填

测试完成后必须回填：

- 固件 commit、板号、电池包编号、仪器和环境温度。
- 原始 CSV 与异常时刻的完整串口日志。
- PACK 与 6 节单体曲线。
- BQ 电流和 SC8815 IBUS/IBAT 曲线。
- VBATS、实际截止电压、最高单体和停止原因。
- 温度曲线、EOC、fault、CHG/DSG 状态。
- 配置阈值、理论值、实测触发值和误差。
- 是否允许进入最终闭环的结论。
