# 代码清洗顺序策略

更新日期：2026-07-12

## 1. 目标

本轮清洗只处理已经确认需要修复、且会影响项目闭环的项目。Debug CLI 继续作为 AI 上板抓日志、发命令和采集 CSV 的入口，必须保留到充电曲线验证完成后；不为即将删除的 AI 专用接口追加长期生产架构。

最终顺序固定为：

```text
文档决策冻结
→ 完成必要代码清洗
→ 充电曲线与阈值测试
→ 结果回填
→ 冻结 release commit
→ 完整项目开发文档
```

## 2. 本轮不处理项

- AI Debug CLI 的 BQ 并发访问问题：接口后期整体删除，不做长期 mutex/service 改造。
- `xTaskCreate()` 返回值检查：保留当前教学展开习惯。
- 看门狗：本轮延期，不作为闭环阻塞项。
- Debug CLI 默认 CSV：继续保留用于 AI 调试和曲线采集。
- CI、静态分析和自动化门禁：当前阶段不建设。

## 3. 本轮必须完成的代码清洗

### 3.1 预放电生产闭环

当前 PDSG 单独控制主要存在于 CLI 探测路径，正常功率状态机必须补齐：

1. 进入放电前先进入预放电状态。
2. 仅释放 PDSG，保持 DSG 关闭。
3. 通过 PACK/LD 压差、硬件可测条件或明确超时判断预放电是否完成。
4. 成功后切换到 DSG；失败时关闭全部放电 FET 并进入安全状态。
5. 保留 CLI `pdsg probe` 作为定位工具，但生产链路不得依赖 CLI 才能工作。

### 3.2 SC8815 INT CubeMX 配置

- 将 `PA5 / SC8815_INT` 从普通输入改为 EXTI。
- ISR 只置 pending flag，禁止在 ISR 内访问软件 IIC。
- `sc8815_task` 消费 pending flag 后读取 STATUS/ADC。
- 保留周期轮询作为丢中断兜底。

### 3.3 RTOS 周期写法

- 所有毫秒参数使用 `pdMS_TO_TICKS()` 转换。
- `batman_task`、`sc8815_task` 等固定周期任务使用 `vTaskDelayUntil()`。
- Debug CLI 可以继续使用较短周期，但仍应使用 tick 转换。
- 不在本轮改变任务优先级和教学式任务展开结构。

### 3.4 外设初始化失败禁止 RUN

- 检查 `Int_CanFd_Init()`、`Int_EEPROM_Init()` 等项目要求外设的初始化返回值。
- 任一必需外设初始化失败时，不创建正常业务任务或不进入正常 RUN。
- 系统保持充放电安全态，并通过现有串口/OLED/LED 输出明确故障。
- 若后续确认某外设可选，再单独把它改为降级运行，不得默认忽略错误。

## 4. 只更新规则、不改功能的事项

- BQ76952 项目默认 CRC 改为 `disabled`；INT 层继续保留 CRC 支持。
- 新版硬件删除原 BQ WAKE/TS2 通道；软件不得依赖或驱动 PB3 唤醒。
- 更新早期文档中的裸机、无构建入口、无 `.gitignore`、旧仓库名和旧分支信息。
- 将实测数据迁移到可追溯目录结构，不再只按通用 CSV 文件名堆放。

## 5. BQ 事务阻塞问题的处理边界

`Int_BQ76952` 中的 echo/config 轮询、`HAL_Delay()` 和 I2C timeout 可能造成高优先级任务长时间阻塞。该问题本轮先完成技术说明和最坏耗时测算，不直接改代码，避免在充电测试前扰动已通过的放电链路。

只有在以下任一条件成立时再进入代码整改：

- 实测出现 SC 任务或功率决策明显延迟。
- BQ 通信异常导致单次任务执行时间超过安全响应预算。
- 充电曲线出现与 BQ 阻塞相关的采样断点或控制延迟。

## 6. 充电测试任务

清洗完成后，按 `docs/test/ai_charge_curve_test_task.md` 执行。计划日期为 **2026-07-13**，实际执行以清洗代码编译、烧录和基础回归完成为前提。

已知基线：

- 完整放电测试已通过当前阶段验证。
- 充电测试仍需完成。
- 保护阈值在测试中记录和核对，不在测试前凭经验继续改动。
- Debug CLI 和默认 CSV 在本阶段继续保留。

## 7. 清洗后的最低回归

1. 冷启动，不发送 CLI 命令，确认 BQ/SC 自动初始化。
2. 确认 CAN、EEPROM 初始化失败时不能进入正常 RUN。
3. 确认 SC8815 INT 可以触发 pending flag，任务能读回状态。
4. 确认预放电成功、超时和失败关断三条路径。
5. 确认完整放电功能没有因本轮清洗退化。
6. 确认 CSV 仍可稳定采集 PACK、6 节单体、电流和时间。
7. 通过后再进入充电曲线测试。
